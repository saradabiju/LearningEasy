Basic HTML Concepts

  • HTML Tags: Tags like <p>, <h1>, and <div> define the structure.
  • Attributes: Provide extra information like <a href="url"> for links.
  • Headings: Use <h1> to <h6> for titles.
  • Paragraphs: Use <p> to add text.
  • Formatting: Use <b> for bold, <i> for italic.
  • Links: Use <a> to create clickable links.
  • Lists: Use <ul> for bullet points and <ol> for numbered lists.
  • Images: Use <img src="image.jpg"> to display pictures.

Basic HTML Syntax

<p>This is a paragraph</p>

<em>This is emphasized text</em>

<i>This is italic text</i>

<b>This is bold text</b>

<mark>This is highlighted text</mark>
