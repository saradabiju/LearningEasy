Basic HTML Concepts 🏗️

  • 📌 HTML Tags: Tags are the building blocks of a webpage.
    Example: <p>Hello, World!</p>
  • 🔗 Attributes: Attributes add extra information to tags.
    Example: <a href="https://example.com">Click Me</a>
  • 🔠 Headings: Headings define titles of sections.
    Example: <h1>Big Title</h1>
  • 📄 Paragraphs: Used for writing text.
    Example: <p>This is a paragraph.</p>
  • ✨ Formatting: Used to style text.
    Example: <b>Bold Text</b>, <i>Italic Text</i>
  • 🔗 Links: Create clickable links.
    Example: <a href="https://example.com">Visit Site</a>
  • 📋 Lists: Used to list items.
    Example: <ul><li>Item 1</li><li>Item 2</li></ul>
  • 🖼️ Images: Add pictures to webpages.
    Example: <img src="image.jpg" alt="A picture">
